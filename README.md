# Mint's Online Social Media Coach

เว็บติวข้อสอบปรนัย CDM3210 / MCS3380 สื่อสังคมออนไลน์ (บทที่ 1–9) — ไม่ต้องสมัคร ไม่ต้องล็อกอิน

ที่มา: ภาพสไลด์ 33 หน้าจากคลิปบรรยายสรุป (class 10) ข้อที่ติดป้าย "เสริม นอกสไลด์" เป็นความรู้ทั่วไปที่ควรตรวจกับตำรา

แก้ไขข้อสอบ: แก้ `source/bank/chNN.json` (`c[0]` = คำตอบที่ถูก, `w` = เหตุผลที่ c[1..3] ผิด, `x: 1` = นอกสไลด์) → รัน `validate.py` และ `build.py` (ปรับ path ตัวแปร `B`) → แทนที่ `index.html` แล้ว commit
